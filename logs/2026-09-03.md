## Self-check (into today's log, from memory)

1. Absolute vs relative path — define each; when does a relative path betray you?<br>
A. Abs path is the complete file path. Relative path is the path from the current working directory. A relative path betrays you when you are not in the expected working directory.
2. What are `.` and `..`? What does `cd -` do?<br>
A. '.' is the current directory and `..` is the parent directory. `cd -` takes you back to the previous working directory.
3. Which command renames a file, and why does that make sense given its real job?<br>
A. `mv` renames a file. It makes sense because it moves the file from one name to another. linus is file sysetem, everything is a file, so renaming is moving the file to a new name.
4. Why is `rm` more dangerous than deleting in Windows Explorer? State the covenant.<br>
A. `rm` is more dangerous because it permanently deletes files without sending them to a recycle bin. The covenant is to always double-check the command and use the `-i` flag for interactive deletion to avoid accidental loss.
5. You need the last 50 lines of a growing log file, live. Exact command?<br>
A. `tail -n 50 -f logfile`
6. What's the difference between `>` and `>>`?<br>
A. `>` writes output to a file, overwriting its contents. `>>` appends output to the end of a file.
7. Where in the tree do: config files, logs, your own work — live?<br>
A. Config files live in `/etc`, logs live in `/var/log`, and your own work lives in your home directory `~`.
